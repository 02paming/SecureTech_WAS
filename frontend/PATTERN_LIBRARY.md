# SecureTech 패턴 라이브러리

화면설계서의 공통 규칙으로 사용하는 UI 목록입니다. 실제 정의는 `src/App.css`에 있으며, 새 화면은 이 목록 안에서 종류를 골라 만듭니다.

## 1. 공통 값

| 구분 | 값 | 사용처 |
|---|---|---|
| 글자 크기 | 11px | 표 안 버튼, 태그, 보조 설명 |
| | 12px | 시간, 표(소형), 안내 문구 |
| | 13px | 본문, 표, 입력칸 |
| | 14px | 강조 값, 작은 제목 |
| | 16px | 카드 제목 |
| | 20px | 페이지 제목 |
| | 24px | 통계 수치 |
| | 28px | 홈 대표 문구 (홈 전용) |
| 모서리 | 4px | 태그 |
| | 6px | 버튼, 입력칸, 상태 뱃지 |
| | 8px | 표, 정보 상자 |
| | 12px | 카드, 창 |
| 간격 | 6 / 8 / 12 / 16 / 24px | 요소 사이 간격 |

## 2. 색상

| 이름 | 라이트 | 다크 | 의미 |
|---|---|---|---|
| Primary | `#0284c7` | `#0ea5e9` | 실행, 새로고침, 선택됨, 링크 |
| Success | `#10b981` | `#34d399` | 허용, 승인, 정상 |
| Danger | `#ef4444` | `#f87171` | 차단, 삭제, 해제, 위험 |
| Warning | `#f59e0b` | `#fbbf24` | 의심, 주의 |
| Neutral | 테두리 `#cbd5e1` | 테두리 `#475569` | 취소, 닫기, 다운로드, 보조 동작 |

- 관리자 로그인 화면만 Primary를 `#851216`(다크 `#f87171`)으로 바꿔 일반 로그인과 구분합니다.
- 차트 색은 정상 `#38bdf8`, 위협 `#f87171`, AI 의심 `#f59e0b`이고, 원그래프는 순위별 5색을 사용합니다.

## 3. 버튼

크기, 너비, 색을 각각 하나씩 골라 조합합니다.

| 크기 | 높이 | 클래스 | 사용처 |
|---|---|---|---|
| S | 26px | `btn-action` | 표 안 조치, 작은 보조 버튼 |
| M | 32px | `btn-action btn-header` | 페이지 상단, 카드 상단, 창 하단 |
| L | 36px | `btn-action btn-form` | 입력칸·검색창 옆 |
| XL | 44px | `btn-action btn-block` | 로그인·가입 제출 (전체 너비) |

| 너비 | 값 | 클래스 | 사용처 |
|---|---|---|---|
| 초소형 | 44px | `btn-w-xs` | 전체/허용/차단 같은 2글자 필터 |
| 소 | 60px | `btn-w-sm` | 2~4글자 |
| 중 | 90px | `btn-w-md` | 일반 버튼 |
| 대 | 120px | `btn-w-lg` | 5~7글자 |
| 자동 | 글자 + 좌우 14px | `btn-w-auto` | 건수가 함께 나오는 긴 문구 |

| 색 | 클래스 | 사용 문구 |
|---|---|---|
| Primary | `btn-primary` | 새로고침, 저장, 등록, 적용, 시작 |
| Success | `btn-success` | 허용, 승인, 허용 이관 |
| Danger | `btn-danger` | 차단, 반려, 해제, 퇴사, 삭제, 로그아웃 |
| Warning | `btn-warning` | 예비 (현재 미사용) |
| Neutral | `btn-neutral` | 취소, 닫기, 수정, 초기화, CSV 다운로드, 관리 |
| Outline | `btn-outline` | 보호, 실시간 위치로 |
| Toggle | `btn-toggle` + `active` | 켜고 끄는 필터, 탭형 선택 |

## 4. 뱃지와 태그

| 종류 | 모양 | 클래스 | 사용처 |
|---|---|---|---|
| 상태 뱃지 | 높이 26px, 모서리 6px | `status-badge` + 색 | 정상 통과, 차단, 인증 완료 |
| 건수 뱃지 | 모서리 6px | `count-badge` + 색 | 총 3건, 대기 신청 0건 |
| 태그 | 모서리 4px, 테두리 | `tag` / `tag-primary` / `tag-mono` | ID, 권한, MAC 주소, 안내 문구 |

뱃지 색은 `badge-primary`, `badge-success`, `badge-warning`, `badge-danger`, `badge-gray` 5가지입니다.

## 5. 입력

| 종류 | 규격 | 클래스 |
|---|---|---|
| 입력칸, 선택 상자 | 높이 36px | `custom-input` (`select-input`) |
| 검색창 | 높이 36px, 너비 300px | `custom-input search-input` |
| 날짜 | 높이 36px, 너비 140px | `custom-input date-input` |
| 여러 줄 입력 | 높이 자동 | `textarea.custom-input` |
| 라벨 / 힌트 / 검증 문구 | 13px / 11px / 12px | `form-label` / `form-hint` / `form-message` |

**검색창 위치**
- 카드 하나만 검색: 카드 왼쪽 위 (`card-toolbar`)
- 페이지 전체 검색: 상단 영역, 최종 갱신 시간 왼쪽

## 9. 정보 표시

| 종류 | 클래스 | 사용처 |
|---|---|---|
| 통계 카드 | `stat-card` + `tone-*` | 건수를 누르면 표가 걸러지는 카드 |
| 정보 상자 | `info-box` | 창 안의 묶음 정보 |
| 항목 줄 | `info-row`, `info-label`, `info-value` | 이름: 값 형태 |
| 안내 상자 | `notice-box` + `tone-*` | 안내사항, 주의 문구 |
| 진행 막대 | `progress`, `progress-fill` | 보안 점수, 준수율 |
| 목록 줄 | `list-row` | 대시보드 대기열, 최근 로그 |
| 빈 화면 | `empty-state` | 데이터가 없을 때 |

## 10. 작성 규칙

1. 이모지는 쓰지 않습니다. 필요하면 ▲ ▼ ✓ ← → 같은 단순 문자만 사용합니다.
2. 같은 문구의 버튼은 어느 화면에서든 같은 색으로 만듭니다.
3. 시간 표시는 `최종 갱신: 18시 30분 15초` 형식(ko-KR 24시간제)을 사용합니다.
4. 색상 코드는 `App.css`의 변수로만 지정합니다. 원그래프 5색만 코드에 둡니다.
5. 인라인 스타일은 실행 중에 계산되는 값(점수 막대 너비, 끌어서 바꾸는 열 너비, 서버가 주는 색)과 표의 열 너비에만 사용합니다.
